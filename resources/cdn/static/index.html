Kuttab Othman CDN

Here you will find multiple public annotated Quran mushaf editions.

These are the following available mushaf EDITIONS (also found in editions.json) :

  • Tajweed
  • MedinaOld
  • Warsh1

How to access to quran resources :

  • Editions Metadata: editions.json
  • Quran Metadata: quran.json
  • Mushaf: {EDITION}/pages/001.png - {EDITION}/pages/604.png
  • Ayat BBoxes: {EDITION}/book_{EDITION}_bbox.json
  • Ayat BBoxes Reversed: {EDITION}/book_{EDITION}_bbox_reversed.json
  • Ayat BBoxes Normalized: {EDITION}/book_{EDITION}_bbox_norm.json
  • Ayat BBoxes Reversed Normalized: {EDITION}/book_{EDITION}_bbox_reversed_norm.json

The JSON file contains bounding boxes for each ayah, including:

  • Absolute ayah numbers
  • Page numbers
  • Top, left, bottom, right bbox coordinates
